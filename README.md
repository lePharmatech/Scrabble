# Scrabble

🎓 Projet académique CS50 (Harvard University)

Implémentation en C d'un programme évaluant le score de deux mots saisis par deux joueurs selon le barème de points officiel du Scrabble, afin de déterminer qui l'emporte.

# Fonctionnalités :

- Attribution dynamique des points pour chaque lettre (indépendamment de la casse).

- Prise en compte explicite des caractères non alphabétiques (0 point).

- Détermination du résultat final (Player 1 wins!, Player 2 wins! ou Tie!).
